# STM32 智能蓝牙温度计

基于 STM32F103 + T117 温度传感器 + KT6368A 蓝牙模块的智能温度计，支持 OLED 实时显示和手机 APP 远程读取温度。

## 项目简介

本项目是一个完整的智能温度计解决方案，涵盖硬件设计、嵌入式固件和手机端 APP。MCU 通过 I2C 采集 T117 温度传感器数据，在 0.96 寸 OLED 屏幕上实时显示温度，同时通过串口将数据透传至 KT6368A 蓝牙模块，手机端 APP（Android / HarmonyOS）通过 BLE 连接接收并展示温度数据。

## 功能描述

- **温度采集**：T117 传感器通过 I2C 接口持续采集环境温度
- **OLED 显示**：0.96 寸屏幕实时显示当前温度值
- **蓝牙透传**：KT6368A 模块通过串口接收温度数据，BLE 广播至手机
- **手机 APP**：Android / HarmonyOS 双平台 APP，支持 BLE 连接、温度接收、通知栏常驻显示

## 硬件方案

| 模块 | 型号 | 接口 | 说明 |
|------|------|------|------|
| 主控 | STM32F103C8T6 | - | ARM Cortex-M3，72MHz |
| 温度传感器 | T117 | I2C（PB10-SCL, PB11-SDA） | 精度 ±0.1°C，支持连续/单次转换，32次平均滤波 |
| 显示屏 | 0.96" OLED（SSD1306） | I2C（PB6-SCL, PB7-SDA） | 128×64 分辨率，中文显示 |
| 蓝牙模块 | KT6368A | UART（PA9-TX, PA10-RX） | SPP/BLE 双模，串口透传，115200 波特率 |

## 工作原理

1. **温度采集**：T117 以每秒 2 次的频率连续采集温度，经 32 次平均滤波后输出稳定值
2. **OLED 显示**：MCU 读取温度后通过 I2C 驱动 OLED 屏幕实时显示，500ms 刷新一次
3. **蓝牙透传**：MCU 通过串口将温度数据发送至 KT6368A 模块，模块自动通过 BLE 广播
4. **手机接收**：APP 扫描并连接 BLE 设备，接收温度数据并在界面和通知栏显示

## T117 传感器关键参数

- 温度范围：-40°C ~ +125°C
- 分辨率：1/256°C（约 0.004°C）
- 精度：±0.1°C（典型值）
- 转换公式：`温度 = 25.0 + 原始数据 / 256.0`
- I2C 写地址：0x80，读地址：0x81

## 功能亮点

- **双平台 APP 支持**：同时提供 Android（Kotlin）和 HarmonyOS（ArkTS）手机端，覆盖主流移动生态
- **BLE 通知栏常驻**：Android APP 支持通知栏实时显示温度，无需打开 APP 即可查看
- **高精度采集**：T117 传感器支持 32 次平均滤波，采样精度达 ±0.1°C，分辨率 1/256°C
- **软件 I2C 驱动**：T117 和 OLED 均采用软件模拟 I2C，引脚分配灵活，便于移植到其他 STM32 型号
- **中文 OLED 显示**：屏幕直接显示"智能温度计"标题和温度数值，开箱即用
- **低功耗设计**：T117 支持低功耗模式，适合电池供电场景
